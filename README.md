# ESwitch

PIC10F200を使用した、モーメンタリスイッチでリレー接点（NC/NO）を切り替えるファームウェアです。  
電源投入時はNC側がON（GP0=Low）で起動し、GP3のスイッチ押下のたびにNC/NOをトグルします。

## 想定ハードウェア構成

- マイコン: PIC10F200
- 電源: 5V想定
- スイッチ: モーメンタリ（GP3）
- 出力: リレー駆動1系統（GP0）、状態表示LED 2系統（GP1/GP2）

## ピン接続

- **GP0（プッシュプル出力）**  
  リレーコイル駆動用。トランジスタ/MOS-FET等を経由してリレーコイルを駆動
- **GP1（プッシュプル出力）**  
  LED（NC: Normally Closed表示）を電流制限抵抗経由で接続。NC側ON時に点灯
- **GP2（プッシュプル出力）**  
  LED（NO: Normally Open表示）を電流制限抵抗経由で接続。NO側ON時に点灯
- **GP3（プルアップ入力）**  
  プッシュスイッチ（モーメンタリ）を接続

## 使い方（利用者向け）

1. 上記のとおりに配線します。  
2. PIC10F200へ本ファームウェアを書き込みます。  
3. 電源投入でNC側ON状態になります。  
4. GP3スイッチを押すたびに、NC/NOが交互に切り替わります。  

## 動作仕様

- 電源投入（リセット）直後:
  - 状態をOFF（`sw_state = 0`）へ初期化
  - GP0=0, GP1=1, GP2=0 に設定（NC側ON）
- スイッチ押下時:
  - チャタリング判定（約19.2ms）を通過した押下のみ有効
  - `sw_state` を反転し、リレーとLED表示を切り替え
- 連続押下抑制:
  - 切り替え後500msは再押下を無効化
- 待機:
  - ボタンリリース確認後にSLEEPへ移行
  - GP3の変化でウェイクアップし、再度押下判定を実施

## 内部の動き（実装解説）

### 1. 初期化（`system_init`）

- `OPTION`レジスタで以下を設定:
  - GP3ウェイクアップ有効
  - GP3内部プルアップ有効
  - TMR0クロック = Fosc/4
  - プリスケーラ = 1:128
- `TRISGPIO = 0b00001000`  
  GP3のみ入力、GP0/GP1/GP2を出力に設定

### 2. 押下/リリース判定（`button_wait`, `button_check`）

- TMR0を使い、約19.2ms同じ入力状態が継続することを確認
- `button_check` は判定成功時のみ「有効な押下」として処理継続

### 3. 出力更新（`set_gpio`）

- `sw_state = 0`（NC側）:
  - GP0=0（接点はNC側）
  - GP1=1（NC LED ON）
  - GP2=0（NO LED OFF）
- `sw_state = 1`（NO側）:
  - GP0=1（接点はNO側）
  - GP1=0（NC LED OFF）
  - GP2=1（NO LED ON）

### 4. メインループ（`main`）

- パワーオン時は初期状態設定と起動時LED点滅を実施
- スリープ復帰時は押下成立時のみ状態反転
- 毎サイクル最後にリリース待ちしてSLEEPへ戻る
